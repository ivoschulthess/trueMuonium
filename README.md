# Feasibility of Low-Energy True Muonium Photoproduction

[![DOI](https://zenodo.org/badge/doi/10.5281/zenodo.21873825.svg)](https://doi.org/10.5281/zenodo.21873825)
[![Release](https://img.shields.io/github/v/release/ivoschulthess/trueMuonium)](https://github.com/ivoschulthess/trueMuonium/releases)
[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/ivoschulthess/trueMuonium/HEAD?labpath=analysis.ipynb)

This repository contains the simulation and analysis code, together with the preprocessed simulation data, accompanying the paper **"Feasibility of Low-Energy True Muonium Photoproduction."**

The study investigates the feasibility of producing low-energy true muonium (TM) via near-threshold photoproduction on a fixed target, including the expected signal, dominant backgrounds, and possible precision measurements.


## Contents

The repository contains:

- preprocessed simulation data for the TM signal and electron--positron background;
- analysis notebooks used to process the simulated data and calculate the observables presented in the paper.


## Reproducing the analysis

The analysis can be run locally using the provided notebooks and preprocessed data. Alternatively, the analysis can be opened interactively with Binder using the badge above.
